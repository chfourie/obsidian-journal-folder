# Welcome to the Journal Folder demo vault

This vault shows the **Journal Folder** plugin running on two journals:

- **[[Personal/journal-folder|Personal]]** — everyday journaling with daily goals.
- **[[Project — Atlas/journal-folder|Atlas Migration]]** — a project journal tracking a database migration.

Open the calendar in the right sidebar and jump to **today**, or browse a
journal folder to see daily, weekly, monthly, quarterly and yearly notes.

## Task flow (Bullet Journal)

| Marker | Status |
|---|---|
| `[ ]` | Open |
| `[/]` | In progress |
| `[x]` | Done |
| `[-]` | Cancelled |
| `[d]` | Delegated |
| `[>]` | Migrated — moved to another note |

Click a checkbox to cycle it, or click to open the status picker. Migrated
tasks leave a `lucide:redo` link to where they went, and the destination gets
a `lucide:undo` link back.

## Task categories

The task sidebar groups tasks by category: **Important**, **Daily Goals**,
**Targets** and **Appointments**. Monthly and weekly notes use
` ```journal-tasks ` blocks to roll up the tasks below them.
